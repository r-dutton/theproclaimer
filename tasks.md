# Tasks

- [x] Fix missing request processor dispatch details when `ProcessAsync` is invoked with a `var` initialized from another method call. Currently flows like `DataGet.Api.Controllers.Connections.AccountingFileController.DeleteJournal` end with "no dispatches detected" even though the handler forwards the request returned by `_externalApiServiceFactory`. Update the analyzer so local variables initialized via invocations capture their concrete request types, allowing the flow to surface the downstream call.
- [x] Ensure service analyzers treat `IControlledRepository<>` (and other generic repository abstractions) as repositories. Right now services such as `DataGet.Connections.App.Services.ConnectionService` show no repository operations in flows even though they call `WriteQuery`, `Add`, and `Remove`. Updating repository detection should expose these read/write edges through the service expansion.
- [ ] Capture domain aggregate method invocations so Cirrus flows surface business operations performed after loading tracked entities. Examples: `ReportTemplatesController.Create` never mentions `ReportTemplateManager.CreateReportTemplate`, and `FilesController.AddEntity`/`AccountsController.BulkChildUpdate` omit `file.AddEntity`, `childAccount.Update`, and `childAccount.Detach` despite those shaping the response.
- [ ] Ensure direct `return _requestProcessor.ProcessAsync(new Query(...))` patterns emit dispatch edges. Dataverse's `ClientsController.GetAllAudits` flow currently reports "no dispatches detected" even though it sends `GetDataverseExternalAuditQuery`.
- [ ] Teach the HTTP analyzer to understand typed wrapper methods (e.g., `PostHttpResponseAsync`, `DeleteHttpResponseAsyncWithClientCredentials`, `IManageApiClient.Request`) so flows like `FyiController.Authenticate`, `IManageController.DownloadDocument`, and Workpapers' `AutoInsertController.Post` get real verbs/routes instead of `remote_endpoint_metadata_missing`.
- [ ] Stop treating pure service abstractions such as `IApiService.GetFeatures` as HTTP clients. Cirrus' `JournalController.Create` erroneously shows a remote call to `IApiService` even though the implementation only selects feature objects.
